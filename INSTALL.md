# Установка Подсказыча

Инструкция для тех, кто просто хочет пользоваться приложением. Как собрать его из исходников — в разделе [«Для разработчиков»](README.md#для-разработчиков) README.

## 1. Что понадобится

| | |
| --- | --- |
| **Система** | Windows 10 (версия 2004 и новее) или Windows 11, 64 бита |
| **Память** | от 8 ГБ оперативной памяти |
| **Диск** | около 3 ГБ свободного места |
| **Видеокарта** | не обязательна. С NVIDIA распознавание речи идёт на видеокарте, без неё — на процессоре, та же модель и то же качество, фраза расшифровывается примерно за 1–2 секунды |
| **Подсказки** | подписка у одного из сервисов ниже — или локальная модель через Ollama, тогда ни подписка, ни интернет не нужны |

Распознавание речи целиком встроено в установщик: Python, модель Whisper и библиотеки для видеокарт NVIDIA ставятся вместе с приложением, ничего докачивать не нужно.

## 2. Скачать

Нажмите кнопку **«Скачать для Windows»** в [README](README.md) или откройте [страницу последнего релиза](../../releases/latest) и скачайте `Podskazych-Setup-x64.exe`.

Установщик весит около 1,5 ГБ: внутри модель распознавания речи.

Проверить, что файл не подменён, можно по контрольной сумме из `SHA256SUMS.txt` в том же релизе:

```powershell
Get-FileHash .\Podskazych-Setup-x64.exe
```

## 3. Установить

1. Запустите `Podskazych-Setup-x64.exe`.
2. Windows может показать синее окно **«Система Windows защитила ваш компьютер»**. Установщик не подписан платным сертификатом, и Windows просто ещё не знает эту программу — это не значит, что файл заражён. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Права администратора не нужны: приложение ставится только для текущего пользователя.
4. После установки на рабочем столе появится ярлык **«Подсказыч»**.

> В Windows 11 с включённым **Smart App Control** кнопки «Выполнить в любом случае» нет — Windows блокирует любые неподписанные программы. Проверить: «Параметры → Конфиденциальность и защита → Безопасность Windows → Управление приложениями и браузером → Smart App Control».

## 4. Подключить подсказки

Подсказки пишет языковая модель. Подсказыч не хранит ни ключей, ни паролей: он запускает на вашем компьютере официальную программу сервиса, в которую вы входите сами. Выберите один вариант — переключаться можно в любой момент кнопкой модели в строке запроса или в **«Настройки → Основные → Кто отвечает»**.

Команды ниже вводятся в **PowerShell** (Пуск → «PowerShell»). После установки программы **перезапустите Подсказыч**, чтобы он её увидел.

### Claude — через Claude Code

Нужна подписка Claude Pro, Max, Team или Enterprise.

```powershell
irm https://claude.ai/install.ps1 | iex
```

Вход: откройте новое окно PowerShell, выполните `claude` и войдите в браузере.

Вместо подписки можно указать ключ Anthropic API: **«Настройки → Основные → Как обращаться к Claude → API по ключу»** и переменная окружения `ANTHROPIC_API_KEY`. Оплата тогда идёт по токенам.

### ChatGPT — через Codex CLI

Нужна подписка ChatGPT (Plus, Pro, Business или другая с доступом к Codex).

```powershell
irm https://chatgpt.com/codex/install.ps1 | iex
```

Вход: `codex login` — откроется браузер.

### Cursor — через Cursor Agent

Нужен аккаунт Cursor. Одна подписка даёт модели Claude, GPT, Gemini, Grok и собственные модели Cursor.

```powershell
irm 'https://cursor.com/install?win32=true' | iex
```

Вход: `agent login`.

### Gemini — через Antigravity CLI

Нужен аккаунт Google.

```powershell
winget install Google.AntigravityCLI
```

Вход: выполните `agy` и войдите в браузере.

### Локальная модель — через Ollama

Работает без интернета: ни расшифровка, ни вопрос не уходят в сеть. Качество и скорость зависят от модели и мощности компьютера.

1. Скачайте и установите Ollama с [ollama.com/download](https://ollama.com/download).
2. Скачайте модель, например: `ollama pull qwen3:8b`.

### Проверить подключение

Нажмите кнопку модели в строке запроса. У каждого сервиса стоит метка:

- **подключён** — всё готово;
- **нужен вход** — программа установлена, но вы не вошли: нажмите «Войти», откроется окно с командой входа;
- **не установлен** — нажмите «Как установить», там команда из этой инструкции.

## 5. Первый запуск

1. При первом запуске зверёк проведёт короткое обучение — его можно пропустить и вернуть из меню.
2. Нажмите круглую кнопку или <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>S</kbd> — начнётся сессия. Windows спросит доступ к микрофону — разрешите.
3. Включите звук созвона: голубая волна — собеседник, лаймовая — вы.
4. Нажмите <kbd>Ctrl</kbd> <kbd>⇧</kbd> <kbd>Space</kbd> — появится подсказка.

В строке состояния видно, где идёт распознавание: `· cuda` — на видеокарте NVIDIA, `· процессор` — на процессоре.

## 6. Частые проблемы

| Что видно | Что сделать |
| --- | --- |
| Сервис помечен «не установлен», хотя вы его поставили | Перезапустите Подсказыч. Если не помогло — выйдите из учётной записи Windows и войдите снова, чтобы обновился путь к программам |
| «Нужен вход» | Нажмите «Войти» и завершите вход в открывшемся окне, затем «Проверить снова» |
| «Лимит исчерпан» | Лимит подписки на текущий период закончился — дождитесь сброса или переключитесь на другой сервис |
| Нет голубой волны собеседника | В меню выберите устройство вывода, через которое идёт звук созвона |
| Распознавание на процессоре, хотя есть NVIDIA | Обновите драйвер видеокарты; причина написана в «Настройки → Основные → Распознавание речи» |
| Панель не видна в демонстрации экрана | Так и задумано: окно скрыто от захвата. Отключается в настройках |
| Горячая клавиша не срабатывает | Её занял другой процесс — приложение взяло запасную, какую именно, видно в «Настройки → Горячие клавиши» |

## 7. Обновление и удаление

- **Обновление:** скачайте новый установщик и запустите его поверх — настройки и журнал созвонов сохранятся.
- **Удаление:** «Параметры → Приложения → Установленные приложения → Подсказыч → Удалить». Настройки, журнал созвонов и текст файлов контекста лежат в `%APPDATA%\Call Copilot` — удалите папку вручную, если они не нужны.

## 8. Что уходит в сеть

Звук и распознавание речи не покидают компьютер. В выбранный сервис уходит только текст запроса: расшифровка, ваш вопрос, найденное во встроенной базе и текст прикреплённых файлов контекста (сами файлы остаются на компьютере), а снимки экрана — только по кнопке «Скриншот». С Ollama в сеть не уходит ничего. Подробнее — в разделе [«Приватность»](README.md#приватность) README.

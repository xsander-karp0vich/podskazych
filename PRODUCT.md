# Product

## Platform

web

## Users

Специалист — чаще всего разработчик или консультант 1С, — который проходит
собеседования, ведёт демо доработок и участвует в рабочих созвонах. Русская речь
с английскими терминами.

Сцена: сидит за рабочим столом, шарит экран в Teams / Телемост / Контур.Толк /
Zoom / Meet, говорит в гарнитуру. Панель живёт поверх демонстрируемого
приложения. Волнуется, когда спрашивают то, чего он не помнит наизусть.

## Job

Во время демонстрации ответить точно и спокойно на вопрос коллеги, не роясь
в документации на глазах у всех. Взгляд на панель — доли секунды, между
фразами; читать её надо боковым зрением и вслух своими словами.

## Mechanism

- Распознавание речи идёт **локально**: на видеокарте NVIDIA, а без неё — той же
  моделью на процессоре. Голоса собеседников не покидают машину — это
  принципиальное свойство продукта, а не оптимизация.
- Два аудиоканала (системный звук и микрофон) дают точное разделение «он / я»
  без модели диаризации.
- Подсказка приходит по требованию, а не потоком: пользователь сам решает, когда
  она нужна.
- Режим снимка экрана: разбор того, что показано в этот момент.

## Constraints

- Windows 10 и 11. Оверлей исключён из захвата экрана: он не попадает в демонстрацию,
  запись и скриншоты. Это же значит, что пользователь **не может снять его
  скриншотом** — важное следствие для любой отладки и поддержки.
- Работает поверх чужих окон на любом фоне: тёмная IDE, белый Excel, цветной
  дашборд. Читаемость не может зависеть от того, что снизу.
- Взгляд уходит от веб-камеры — чем ближе панель к верху экрана и чем короче
  текст, тем меньше это заметно.
- Домен 1С: регистр накопления, СКД, БСП, план обмена, обмен через узлы.
- Сеть может идти через прокси, а оплата зарубежных API картой бывает недоступна —
  поэтому подсказки идут через подписки и их официальные CLI, а не по ключам.

## Success

Пользователь отвечает точно и не сбивается. Панель ни разу не перетянула на себя
внимание и не заставила искать в ней глазами нужное место.

## Open decisions

- Источник подсказок: официальный CLI сервиса на подписке пользователя — Claude
  Code, Codex CLI (ChatGPT), Cursor Agent, Antigravity CLI
  (Gemini), — локальная модель через Ollama или API Anthropic по ключу. Второй
  агент-проверщик работает с любым из них, на своей модели. Сессия одна на весь созвон: она поднимается по «Старт»,
  при клике в поле запроса и при смене модели.
- Модель и размышления вынесены в строку запроса, а не спрятаны в настройки:
  их меняют между вопросами. Замерено на живой сессии, до первого слова и до
  конца ответа:

  | модель | размышления | первое слово | целиком |
  |---|---|---|---|
  | Opus 5 | вкл | 1.7 с | 9.5 с |
  | Opus 5 | выкл | 0.9 с | 7.4 с |
  | Sonnet 5 | вкл | 2.8 с | 8.3 с |
  | Sonnet 5 | выкл | 1.1 с | 5.8 с |
  | Haiku 4.5 | вкл | 3.8 с | 7.1 с |
  | Haiku 4.5 | выкл | 1.1 с | 4.8 с |

  Неочевидное: с размышлениями Opus доходит до первого слова быстрее Haiku.
  По умолчанию Opus 5 с размышлениями — ответы заметно содержательнее.
- Каждый созвон пишется в журнал: расшифровка и подсказки, по файлу на созвон,
  только на этом компьютере. Выгрузка — текстом для чтения или JSON целиком.
  Запись выключается одним переключателем: писать разговоры с коллегами без
  возможности это отменить было бы неправильно.
- Словарь распознавания собирается сам из базы вопросов, по теме разговора.
  Целиком база в подсказку не влезает (312 частых терминов против бюджета в
  222 токена), а одна тема влезает почти всегда. Тема определяется поиском по
  репликам; порог покрытия подобран замером — 91% верных тем на формулировках
  из базы. Замеры распознавания на синтезированной речи в живом произношении:
  без словаря 3 термина из 13, с постоянной частью 7, с темой 8; подмен похожих
  слов нет. Своё — имена коллег, проекты, заказчики — пользователь вписывает сам,
  это идёт первым и не обрезается.
- Подсказка распознавателю меняет то, что он выдумывает на тишине: вместо
  «Продолжение следует...» — «Редактор субтитров А.Семкин…». Точный список
  известных галлюцинаций такие варианты пропускал, и с постоянной частью словаря
  все пять видов не-речи попадали в расшифровку. Фильтр ловит семейства
  («субтитр», «продолжение следует», пометки звука капсом), а не строки;
  после этого утечек нет ни в одном режиме.
- База знаний встроена в приложение (kb/questions.jsonl, 982 вопроса с собеседований 1С); своя база пользователя — позже.
